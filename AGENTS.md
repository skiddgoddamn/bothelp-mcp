# AGENTS.md — инструкции для AI-агентов

Этот файл читают кодинг-агенты (Claude Code, Cursor, и т.п.). Если ты — агент и
используешь `bothelp-mcp`, следуй правилам ниже.

## Если наткнулся на ошибку в этом MCP — почини и отправь PR

Проект **открыт для контрибьюций**. Когда во время работы ты встречаешь баг, падение,
неверный payload `ev*`-метода, устаревшую обёртку или несовпадение с реальным протоколом
BotHelp — **не молчи и не костыль на своей стороне**. Исправь в исходнике и отправь фикс на GitHub.

Порядок действий:

1. Определи корень проблемы в `src/index.mjs` (транспорт, обёртка метода, разбор графа).
2. Внеси минимальную правку, чинящую причину (не симптом).
3. Прогони проверки локально:
   ```bash
   npm run check   # node --check синтаксис
   npm test        # оффлайн-смоук: uid/ping/pong/rpc + разбор графа
   ```
   Если добавил нетривиальную логику — допиши проверку в `scripts/smoke.mjs`.
4. Оформи PR в ветку `master` репозитория **skiddgoddamn/bothelp-mcp**:
   ```bash
   git checkout -b fix/краткое-описание
   git commit -am "fix: что и почему"
   gh pr create --repo skiddgoddamn/bothelp-mcp --base master \
     --title "fix: ..." --body "Что сломалось, как воспроизвести, что чинит правка."
   ```
   Если нет прав на пуш — сделай форк (`gh repo fork skiddgoddamn/bothelp-mcp --clone`),
   запушь ветку в форк и открой PR оттуда.
5. В теле PR укажи: как воспроизвёл ошибку, какой запрос/метод её вызвал, что именно поправил.
   Приложи, если можешь, кадр WS-RPC (`{method,data}` / ответ) — это ускоряет ревью.

## Что особенно ценно

- Новые/исправленные обёртки над `ev*`-методами конструктора (сверенные с живым трафиком).
- Уточнения формы payload на запись (`evAddBot`, `evPutComplexBotDiagram`, `evPutComplexBot`).
- Поддержка других мессенджеров, примеры сборки воронок, правки документации.

## Границы

- Не хардкодь неподтверждённые payload — помечай догадки и по возможности проверяй на **тестовом** боте.
- Не коммить секреты (`sessionId`, куки, `.har`) — они в `.gitignore`, держи их там.
- Правь причину в общей функции, а не в каждом вызывающем месте.
